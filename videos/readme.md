# videos

Planos dos vídeos sobre o projeto: o que dizer, por que ordem, com que factos e fontes, e o que mostrar no ecrã. Não são guiões palavra a palavra.

- [`01_problema.md`](01_problema.md): porque comecei, o problema do CPV, as mensagens dos técnicos, quanto custa e o que já se fez lá fora.
- [`notebooks/`](notebooks/): notebooks para mostrar no vídeo, em inglês. Cada um volta a contar, nos dados brutos, um problema dos dados que encontrámos e mostra como o resolvemos. Não tomam decisões; as decisões estão em [`docs/qualidade_dados.md`](../docs/qualidade_dados.md). Correm de qualquer pasta dentro do repositório (procuram o `src/` acima).
  - [`dados_01_ano_do_ficheiro.ipynb`](notebooks/dados_01_ano_do_ficheiro.ipynb): o ano do ficheiro é o ano de assinatura, não o de publicação.
